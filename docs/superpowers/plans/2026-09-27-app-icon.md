# 子辰应用图标 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** 为 Android 应用安装「子辰」品牌名与一枚清晰的十二刻环自适应启动器图标。

**Architecture:** 使用 Android VectorDrawable 绘制前景标记和单色标记，使用颜色资源提供墨色背景，再由 API 26 自适应图标 XML 组合。Manifest 从资源读取应用名称和图标。

**Tech Stack:** Kotlin Android 工程、AndroidManifest、VectorDrawable、Adaptive Icon XML。

## Global Constraints

- 最低系统版本为 Android 8.0（API 26），使用自适应启动器图标。
- 应用显示名称固定为「子辰」。
- 图标沿用墨底 #111210 与古铜金 #C6A56C、浅金 #E5C996。
- 图形保持在 adaptive icon 的安全区域内，不添加小尺寸难辨的文字或外部依赖。

---

## File Map

- Modify app/src/main/AndroidManifest.xml: 指向 @string/app_name 与 @mipmap/ic_launcher。
- Create app/src/main/res/values/strings.xml: 定义应用名「子辰」。
- Create app/src/main/res/values/colors.xml: 定义图标墨底色。
- Create app/src/main/res/drawable/ic_launcher_foreground.xml: 绘制古铜金十二刻环、时针和轴心。
- Create app/src/main/res/drawable/ic_launcher_monochrome.xml: 提供单色主题图标图形。
- Create app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml: 组合自适应图标前景、背景与单色资源。
- Modify docs/superpowers/specs/2026-09-26-bronze-polish-design.md: 记录应用图标的品牌约束。
